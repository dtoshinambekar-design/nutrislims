# NutriSlims Website Redesign - Developer Package

This ZIP contains the complete handoff package requested: design specification, functional requirements, responsive behaviour, working design tokens, starter responsive prototype, generated illustrative image assets, SVG icons/illustrations, mockup references and all three supplied video links.

## Start here
1. Read `docs/01-complete-design-specification.md`.
2. Review `docs/02-functional-requirements.md` and `docs/03-content-plan-and-governance.md`.
3. Open `prototype/index.html` in a browser for the responsive starter demo.
4. Use `design/tokens.json` and `design/tokens.css` as starting points for implementation.
5. Use `videos/videos.json` for the three Drive links and embed URLs.

## Video files
The three videos are hosted in the user's Google Drive. The ZIP includes the original share URLs, file IDs and `/preview` embed URLs, not the binary video files. Public website embedding requires Google Drive sharing set to `Anyone with the link - Viewer`. See `videos/README.md`.

## Important
- Generated food/consultation images are placeholders, not real clinic/patient photos.
- `logo-placeholder.svg` is not the official brand logo. Replace it with the approved logo.
- Confirm current business hours, contact details, credentials, reviews, results and all health-related claims before launch.
- Demo portal credentials visible in the original screenshot must not be copied; rotate them if they were active.
- The HTML prototype is a static starter, not a deployed production site. Booking, client portal, newsletter, analytics and CMS integrations still require backend configuration.
